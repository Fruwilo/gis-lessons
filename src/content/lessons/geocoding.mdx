На этом занятии мы пройдём полный путь от **таблицы с адресами** до **точек на карте**. Геокодирование — это процесс превращения текстового адреса в координаты (широту и долготу). Это одна из самых частых задач в ГИС: у вас есть список объектов (магазины, клиенты, события), но нет координат — и нужно их получить, чтобы нанести на карту.

Мы будем использовать **Яндекс Геокодер** — А точнее его бесплатную (пробную) версию для геокодирования адресов в России и СНГ. Через небольшой скрипт на Python обработаем таблицу Excel, получим координаты и сохраним результат в CSV. А затем загрузим точки в QGIS и оформим карту.

<Callout type="info" title="Что такое геокодирование">
**Геокодирование** (geocoding) — преобразование текстового адреса или названия места в географические координаты (широта, долгота). Обратная операция — **обратное геокодирование**: по координатам получить адрес.
</Callout>

## Шпаргалка: что мы будем делать 

| Этап | Инструмент | Результат |
| --- | --- | --- |
| Подготовить таблицу с адресами | Excel / Google Таблицы | `.csv` с колонками `name`, `address`, `category` |
| Написать скрипт на Python | Python + `requests` | `.csv` с колонками `lat`, `lon` |
| Загрузить точки в QGIS | QGIS | Точечный слой на карте |
| Оформить карту | QGIS | Карта с подписанными точками |

**Логика работы:**

1. Готовим таблицу с адресами — один адрес в одной строке.
2. Python-скрипт по очереди отправляет каждый адрес в Яндекс Геокодер.
3. Сервис возвращает координаты — мы сохраняем их в новую таблицу.
4. Загружаем CSV в QGIS — программа автоматически раскидает точки по широте и долготе.
5. Оформляем: подложка, подписи, символы.

<Callout type="attention" title="Важно: API-ключ Яндекса">
Для работы с Яндекс Геокодером нужен **бесплатный API-ключ**. Получить его можно в [Кабинете разработчика Яндекса](https://developer.tech.yandex.ru/). Для учебных целей лимитов хватит с запасом.
</Callout>

## Часть 2. Геокодирование через Python (~25 мин) || Часть 2. Геокодирование в Python

### Шаг 3 — Напишите скрипт || Шаг 3. Скрипт геокодирования

Создайте в той же папке файл `geocode.py` и скопируйте в него следующий код:

```python
import requests
import pandas as pd
import time

# ═══════════════════════════════════════════════════════
#  НАСТРОЙКИ (Тут уже по желанию, кто-то если хочет может передавать как аргумент, я люблю переменные.)
# ═══════════════════════════════════════════════════════
API_KEY = "ВАШ_API_КЛЮЧ"          # <-- вставьте сюда свой ключ
INPUT_FILE = "addresses.csv"       # входной файл
OUTPUT_FILE = "addresses_geocoded.csv"  # файл с результатами

# ═══════════════════════════════════════════════════════
#  ФУНКЦИЯ ГЕОКОДИРОВАНИЯ
# ═══════════════════════════════════════════════════════
def geocode_address(address: str) -> tuple:
    """
    Отправляет адрес в Яндекс Геокодер и возвращает (lat, lon).
    Если не нашлось — возвращает (None, None).
    """
    url = "https://geocode-maps.yandex.ru/1.x/"
    params = {
        "apikey": API_KEY,
        "geocode": address,
        "format": "json",
        "results": 1,          # только первый (самый точный) результат
    }

    try:
        response = requests.get(url, params=params, timeout=10)
        response.raise_for_status()
        data = response.json()

        # Мы получаем ответ в формате Json , теперь нужно вытащить координаты из ответа
        feature = data["response"]["GeoObjectCollection"]["featureMember"]
        if not feature:
            return None, None

        pos = feature[0]["GeoObject"]["Point"]["pos"]
        lon, lat = pos.split()   # Яндекс возвращает "долгота широта"
        return float(lat), float(lon)

    except Exception as e:
        print(f"  Ошибка для '{address}': {e}")
        return None, None


# ═══════════════════════════════════════════════════════
#  ОСНОВНОЙ ЦИКЛ
# ═══════════════════════════════════════════════════════
if __name__ == "__main__":
    # Читаем исходную таблицу
    df = pd.read_csv(INPUT_FILE)

    # Убедимся, что есть колонка address
    if "address" not in df.columns:
        raise ValueError("В CSV нет колонки 'address'. Проверьте название.")

    print(f"Найдено адресов: {len(df)}")
    print("Начинаем геокодирование...\n") #Небольшое логирование, служит только для трекинга процесса

    latitudes = []
    longitudes = []

    for idx, row in df.iterrows():
        addr = row["address"]
        print(f"[{idx + 1}/{len(df)}] {addr}")

        lat, lon = geocode_address(addr)
        latitudes.append(lat)
        longitudes.append(lon)

        # Пауза 0.3 сек — чтобы не превысить лимиты API, иначе сервис яндекса может заподозрить наши запросы как Brootforce 
        time.sleep(0.3)

    # Добавляем координаты в таблицу
    df["lat"] = latitudes
    df["lon"] = longitudes

    # Сохраняем результат
    df.to_csv(OUTPUT_FILE, index=False, encoding="utf-8-sig")

    # Статистика
    found = df["lat"].notna().sum()
    print(f"\n Готово! Сохранено в '{OUTPUT_FILE}'")
    print(f"   Найдено координат: {found} из {len(df)}")
    if found < len(df):
        print(f"   Не найдено: {len(df) - found} — проверьте адреса вручную.")
```

<Callout type="attention" title="Вставьте свой API-ключ">
В строке `API_KEY = "ВАШ_API_КЛЮЧ"` замените текст на реальный ключ из [Кабинета разработчика Яндекса](https://developer.tech.yandex.ru/).
</Callout>

### Блок 3: Функция `geocode_address` — «позвонить в Яндекс»

```python
def geocode_address(address: str) -> tuple:
    url = "https://geocode-maps.yandex.ru/1.x/"
    params = {
        "apikey": API_KEY,
        "geocode": address,
        "format": "json",
        "results": 1,
    }
```

**`def`** — создаём **функцию** (мини-программу внутри программы). Назвали её `geocode_address`. Она принимает один «ингредиент» — `address` (строку с адресом) — и возвращает два числа: широту и долготу.

> Аналогия: функция — это кофемашина. Кидаешь зёрна (адрес), получаешь кофе (координаты). Не надо каждый раз собирать машину заново.

**`url`** — адрес, куда «звоним». Номер телефона Яндекс Геокодера.

**`params`** — словарь (пары «ключ: значение»), который прикрепляем к запросу:
- `apikey` — кто мы такие (чтобы Яндекс понял)
- `geocode` — сам адрес, который ищем
- `format` — «ответ пришли в JSON» (удобный формат данных)
- `results` — «верни только 1 самый точный результат»

```python
    try:
        response = requests.get(url, params=params, timeout=10)
        response.raise_for_status()
        data = response.json()
```

**`try:`** — «попробуй выполнить код ниже. Если что-то пойдёт не так — не падай, а сделай то, что написано в `except`». Это как надеть шлем перед прыжком.

**`requests.get(...)`** — сам «звонок» в интернет. Библиотека `requests` отправляет GET-запрос (как когда вы вбиваете адрес в браузер). `timeout=10` — «если Яндекс не ответит за 10 секунд, брось и иди дальше».

**`raise_for_status()`** — проверяет: «А не послал ли нас сервер?» Если Яндекс вернул ошибку 403 (нет доступа) или 500 (сервер сломался) — здесь скрипт поймёт это и перейдёт в `except`.

**`data = response.json()`** — ответ от Яндекса приходит в формате JSON (вложенные словари и списки). Команда `.json()` превращает текст ответа в структуру данных Python.

```python
        feature = data["response"]["GeoObjectCollection"]["featureMember"]
        if not feature:
            return None, None

        pos = feature[0]["GeoObject"]["Point"]["pos"]
        lon, lat = pos.split()
        return float(lat), float(lon)
```

Ответ Яндекса — большая матрёшка. Мы лезем внутрь по цепочке:

```
data → "response" → "GeoObjectCollection" → "featureMember"
  → [0] (первый результат) → "GeoObject" → "Point" → "pos"
```

- **`pos`** содержит строку вида `"37.62039 55.75396"` — **сначала долгота, потом широта**.
- **`.split()`** — разрезает строку по пробелу на две части.
- **`float()`** — превращает текст `"55.75396"` в число `55.75396`.
- **`return`** — функция заканчивает работу и отдаёт результат наружу.

```python
    except Exception as e:
        print(f"  Ошибка для '{address}': {e}")
        return None, None
```

Если внутри `try` случилась любая ошибка (нет интернета, Яндекс упал, адрес не найден), мы печатаем сообщение и возвращаем `None, None` — «координат нет». **Скрипт не падает**, а идёт дальше к следующему адресу.

### Блок 4: Основной цикл — обработка всех адресов

```python
if __name__ == "__main__":
    df = pd.read_csv(INPUT_FILE)
```

**`if __name__ == "__main__":`** — классическая «защита от дурака». Говорит Python: «весь код ниже запускай только если файл запущен напрямую». Новичку можно не париться — просто запомните, что так пишут всегда.

**`pd.read_csv(...)`** — Pandas читает CSV и создаёт **DataFrame** — умную таблицу в памяти. `df` — привычное имя для таблицы (от DataFrame). Аналогия: открыли Excel-файл, но внутри Python.

```python
    if "address" not in df.columns:
        raise ValueError("В CSV нет колонки 'address'")
```

Проверяем: «А есть ли в таблице колонка `address`?» Если нет — сразу останавливаемся и кричим ошибку. Лучше упасть сразу, чем молча обработать пустоту.

```python
    latitudes, longitudes = [], []
```

Создаём два пустых **списка** — корзинки, куда будем складывать координаты по одной. Потом прикрепим их к таблице как новые колонки.

```python
    for idx, row in df.iterrows():
        addr = row["address"]
        print(f"[{idx + 1}/{len(df)}] {addr}")

        lat, lon = geocode_address(addr)
        latitudes.append(lat)
        longitudes.append(lon)

        time.sleep(0.3)
```

**`for idx, row in df.iterrows():`** — **цикл**: «пройдись по каждой строке таблицы». `idx` — номер строки (0, 1, 2...), `row` — сама строка со всеми колонками.

> Аналогия: перебираете папки с документами. `idx` — номер папки, `row` — содержимое папки.

**`lat, lon = geocode_address(addr)`** — вызываем нашу функцию из блока 3. Передаём адрес, получаем два числа.

**`.append()`** — кладём координаты в корзинки-списки. После первой итерации: `latitudes = [55.75]`, после второй: `latitudes = [55.75, 59.93]` и так далее.

**`time.sleep(0.3)`** — «подожди 0.3 секунды». Без этого Яндекс подумает, что мы спам-робот, и забанит.

```python
    df["lat"] = latitudes
    df["lon"] = longitudes
    df.to_csv(OUTPUT_FILE, index=False, encoding="utf-8-sig")
```

**`df["lat"] = latitudes`** — приклеиваем список широт к таблице как новую колонку. То же с долготами.

**`.to_csv(...)`** — сохраняем таблицу в файл:
- `index=False` — «не добавляй лишнюю колонку с номерами строк»
- `encoding="utf-8-sig"` — чтобы Excel нормально открыл русские буквы

```python
    found = df["lat"].notna().sum()
    print(f"Готово! Найдено: {found} из {len(df)}")
```

**`.notna()`** — проверяет, какие значения не пустые (не `None`). **`.sum()`** — считает количество `True`. Итого: сколько адресов успешно разобрано.

### Общая схема работы скрипта

1. **Читаем CSV** → получаем таблицу `df`
2. **Цикл по каждой строке**: берём адрес → звоним в Яндекс → получаем `lat`, `lon`
3. **Копим координаты** в списки → приклеиваем к таблице как новые колонки
4. **Сохраняем таблицу** в новый CSV → радуемся жизни

### Типичные ошибки новичков

## Часть 3. Точки на карте в QGIS (~25 мин) || Часть 3. Точки в QGIS

### Шаг 5 — Загрузите CSV в QGIS || Шаг 5. Загрузка CSV

1. Откройте QGIS и создайте новый проект.
2. Меню **Слой → Создать слой → Добавить слой текста с разделителями** (Layer → Create Layer → Add Delimited Text Layer).
3. В открывшемся окне:
   - **Имя файла**: нажмите `…` и выберите `addresses_geocoded.csv`.
   - **Формат файла**: CSV (значения, разделённые запятыми).
   - **Кодировка**: UTF-8.
   - **Поля координат X и Y**: выберите `lon` (долгота) и `lat` (широта) соответственно.
   - **Система координат**: `EPSG:4326` — WGS 84 (это стандарт для координат из интернет-сервисов).
4. Нажмите **Добавить**, затем **Закрыть**.

На карте появятся точки! QGIS автоматически создал **векторный точечный слой** из вашей таблицы — каждая строка стала точкой.

<Callout type="info" title="Про систему координат">
Яндекс Геокодер возвращает координаты в **WGS 84** (EPSG:4326) — в градусах. Для отображения на карте это нормально. Если потом будете считать расстояния или буферы — пересохраните слой в проекционную СК (например, EPSG:32637 для Москвы).
</Callout>

### Шаг 6 — Добавьте подложку || Шаг 6. Подложка

Чтобы точки не «висели в пустоте», добавим фоновую карту через плагин **QuickMapServices**:

1. Меню **Интернет → QuickMapServices → Search QMS**.
2. Введите `yandex` → добавьте подложку **Yandex**.
3. Перетащите подложку **в самый низ** панели Слои.

Теперь точки лежат поверх реальной карты — можно проверить, правильно ли они попали.

### Шаг 7 — Оформите точки и добавьте подписи || Шаг 7. Оформление точек

1. Двойной клик по слою с точками → вкладка **Символика**.
2. Выберите простой символ — круг, цвет яркий (например, красный или синий), размер 4–5 мм.
3. Перейдите на вкладку **Подписи** (Labels):
   - Включите подписи: выпадающий список → **Одно поле** (Single labels).
   - **Значение**: выберите поле `name` (или `address`, если хотите адрес).
   - Настройте размер шрифта (10–11 pt), цвет тёмно-серый.
   - Во вкладке **Размещение** выберите **Смещение от точки** → квадрант «Сверху» или «Справа».
4. Нажмите **OK**.

<Callout type="tip" title="Если подписи налезают друг на друга">
Во вкладке **Подписи → Отображение** поставьте галочку **«Показывать все подписи (включая конфликтующие)»** — тогда QGIS не будет скрывать наложенные. Или уменьшите масштаб, чтобы точек было меньше на экране.
</Callout>

### Шаг 8 — Раскрасьте точки по категориям || Шаг 8. Категории

Поскольку в таблице есть колонка `category`, можно раскрасить точки разными цветами:

1. Двойной клик по слою → вкладка **Символика**.
2. Вверху выпадающий список: выберите **Категоризированный** (Categorized).
3. **Значение**: выберите поле `category`.
4. Нажмите **Классифицировать** — QGIS сам подберёт цвета для каждой категории.
5. Нажмите **OK**.

Теперь магазины, банки, школы и кафе отображаются разными цветами — карта сразу становится информативнее.

### Шаг 9 — Сохраните слой в GeoPackage || Шаг 9. Сохранение в GeoPackage

CSV — это таблица, а не полноценный геоданные. Сохраним точки в формат **GeoPackage**, чтобы они хранились с геометрией:

1. Правый клик по слою с точками → **Экспорт → Сохранить объекты как…**
2. **Формат**: GeoPackage.
3. **Имя файла**: `geocoding_results.gpkg`.
4. **Имя слоя**: `geocoded_points`.
5. **CRS**: оставьте EPSG:4326 (или выберите проекционную СК, если нужно).
6. Поставьте галочку **«Добавить сохранённый файл в проект»** → **OK**.

Теперь у вас есть полноценный векторный слой, который можно открывать в любом ГИС-приложении.

## Бонус 1. Проверка точности || Бонус 1. Проверка точности

Не все адреса геокодируются идеально. Яндекс иногда:
- ставит точку в центр здания, а не у входа;
- находит похожий адрес в другом городе;
- не находит ничего (возвращает `None`).

**Как проверить:**

1. В QGIS включите подложку Yandex Satellite.
2. Приблизьтесь к каждой точке и сравните с реальным положением.
3. Если точка сдвинута — включите **режим редактирования** (значок карандаша), инструментом **Переместить объект** подвиньте точку в правильное место, сохраните изменения.

<Callout type="info" title="Почему координаты могут отличаться">
Геокодер возвращает координаты **центра здания** или **точки привязки адреса** в базе Яндекса. Это не всегда совпадает с реальным входом — особенно для больших зданий, промзон или новостроек.
</Callout>

## Бонус 2. Массовое геокодирование: сотни адресов || Бонус 2. Массовое геокодирование

Если адресов **много** (сотни или тысячи), бесплатный API может не справиться. Варианты:

| Вариант | Когда использовать |
| --- | --- |
| **Яндекс Геокодер (бесплатно)** | До ~1000 адресов в сутки, Россия/СНГ |
| **Яндекс Геокодер (платно)** | Большие объёмы, коммерческое использование |
| **Nominatim (OpenStreetMap)** | Бесплатно, но медленнее и менее точно для РФ |
| **Геокодер 2GIS** | Хорош для адресов в крупных городах РФ |

Для Nominatim замените в скрипте URL и параметры:

```python
def geocode_nominatim(address: str) -> tuple:
    url = "https://nominatim.openstreetmap.org/search"
    params = {
        "q": address,
        "format": "json",
        "limit": 1,
    }
    headers = {"User-Agent": "MyGeocoder/1.0"}  # обязательно!
    response = requests.get(url, params=params, headers=headers, timeout=10)
    data = response.json()
    if data:
        return float(data[0]["lat"]), float(data[0]["lon"])
    return None, None
```

<Callout type="attention" title="Правила использования Nominatim">
Nominatim — публичный сервис OpenStreetMap. **Обязательно** указывайте `User-Agent` и делайте паузу **не менее 1 секунды** между запросами. Без этого IP могут заблокировать.
</Callout>

## Бонус 3. Обратное геокодирование || Бонус 3. Обратное геокодирование

У вас есть координаты, но нет адресов? Яндекс Геокодер умеет и обратную операцию — по `lat, lon` получить адрес.

```python
def reverse_geocode(lat: float, lon: float) -> str:
    url = "https://geocode-maps.yandex.ru/1.x/"
    params = {
        "apikey": API_KEY,
        "geocode": f"{lon},{lat}",   # важно: "долгота,широта"
        "format": "json",
    }
    response = requests.get(url, params=params, timeout=10)
    data = response.json()
    feature = data["response"]["GeoObjectCollection"]["featureMember"]
    if feature:
        return feature[0]["GeoObject"]["metaDataProperty"]["GeocoderMetaData"]["text"]
    return None

# Пример
address = reverse_geocode(55.75396, 37.62039)
print(address)  # Россия, Москва, Красная площадь, 1
```

## Что мы узнали

1. **Геокодирование** — это превращение адреса в координаты. Это базовая операция, без которой невозможна работа с адресными данными в ГИС.
2. **Яндекс Геокодер** — удобный и бесплатный инструмент для адресов в России и СНГ. Нужен API-ключ, но для учебных целей лимитов хватает.
3. **Python + `requests` + `pandas`** — простой способ автоматизировать обработку таблиц. Скрипт обрабатывает сотни адресов без ручной работы.
4. **CSV с координатами** легко превращается в точечный слой в QGIS через **«Добавить слой текста с разделителями»** — главное указать правильные колонки X и Y.
5. **GeoPackage** — удобный формат для хранения результатов: один файл, внутри которого живут и геометрия, и атрибуты.

Этот же подход — **таблица → скрипт → CSV → QGIS** — работает для любых адресных данных: магазины, клиенты, события, ДТП, объекты недвижимости. Главное — правильно подготовить исходную таблицу и проверить точность результатов.
