<Callout type="info" title="Что понадобится">

**Программа:** QGIS **3.40 или новее**.

**Данные:** <a href="https://disk.yandex.ru/d/4QNCFGltnH43yg" target="_blank" rel="noopener noreferrer">архив `tver.zip`</a>. Если он уже скачан, используйте имеющийся файл.

**Результат:** карта вашего МО с границей и населёнными пунктами. В LMS нужно прислать только картинку.

</Callout>

Из общего набора на Тверскую область вы соберёте два слоя: `mo` — граница и площадь территории, `settlements` — её населённые пункты.

---

## Часть 1. Граница и площадь (~10 мин) || Часть 1. Граница и площадь

### Шаг 1 — Подготовьте папку

Создайте папку `Модуль01_практика` с подпапками `data` и `output`. Распакуйте `tver.zip` в `data`.

```text
Модуль01_практика/
├── data/
└── output/
```

### Шаг 2 — Создайте проект

1. **Проект → Создать** (`Ctrl+N`).
2. **Проект → Сохранить как…** → сохраните `Фамилия_МО.qgz` в `Модуль01_практика`.
3. **Проект → Свойства… → Система координат** → найдите `32636` и выберите **WGS 84 / UTM zone 36N**.

В правом нижнем углу должно быть `EPSG:32636`.

### Шаг 3 — Оставьте только своё МО

1. **Слой → Добавить слой → Добавить векторный слой…** → `data\tver.gpkg` → `boundary_mo`.
2. Правой кнопкой по слою → **Фильтр…**.
3. Подставьте свою территорию в выражение:

```sql
"name_short" = 'Кесовогорский'
```

4. **Проверить**: должен найтись один объект. **OK** → правой кнопкой по слою → **Увеличить до слоя**.

Название лучше выбрать в списке значений поля `name_short`, а не набирать вручную.

<Figure src="images/module1-territory-kit/01-filter.png"
        alt="Фильтр слоя boundary_mo по названию муниципального образования"
        caption="После проверки выражения должен остаться один объект." />

### Шаг 4 — Сохраните границу

Правой кнопкой по `boundary_mo` → **Экспорт → Сохранить объекты как…**:

| Поле | Что выбрать |
| --- | --- |
| **Формат** | `GeoPackage` |
| **Имя файла** | `output\Фамилия_МО.gpkg` |
| **Имя слоя** | `mo` |
| **Система координат** | `EPSG:32636` |

Оставьте **Добавить сохранённый слой на карту** и нажмите **OK**. Выключите исходный `boundary_mo`.

<Figure src="images/module1-territory-kit/02-export-mo.png"
        alt="Настройки экспорта границы муниципального образования в GeoPackage"
        caption="Сохраните границу в слой mo внутри своего GeoPackage." />

### Шаг 5 — Посчитайте площадь

1. **Проект → Свойства… → Общие → Измерения**: эллипсоид `WGS 84`, единицы площади — `квадратные километры`.
2. Откройте таблицу атрибутов `mo` (`F6`) → **Калькулятор полей** (`Ctrl+I`).
3. Создайте поле `area_km2`, тип **Десятичное число (real)**, точность `3`.
4. Введите выражение:

```text
$area
```

5. **OK** → **Сохранить изменения слоя** → выключите редактирование.

Делить на миллион не нужно: вы уже выбрали км² в свойствах проекта.

<Figure src="images/module1-territory-kit/03-area.png"
        alt="Калькулятор полей QGIS с полем area_km2 и выражением $area"
        caption="Площадь рассчитывается выражением $area в квадратных километрах." />

<Troubleshoot>

**Фильтр находит ноль объектов.** Выберите название из списка значений `name_short`. Проверьте кавычки: поле — в двойных, значение — в одинарных.

**В `mo` попала вся область.** Повторите экспорт после установки фильтра в шаге 3.

**Площадь выглядит как огромное число в м².** Установите квадратные километры в свойствах проекта и обновите `area_km2` выражением `$area`.

</Troubleshoot>

<Checkpoint title="конец части 1">

- В `mo` один полигон — ваше МО
- СК проекта и слоя — `EPSG:32636`
- Поле `area_km2` заполнено

</Checkpoint>

## Часть 2. Населённые пункты и карта (~10 мин) || Часть 2. Населённые пункты

### Шаг 6 — Добавьте населённые пункты

Из того же `data\tver.gpkg` добавьте слой `rural_settlements`: **Слой → Добавить слой → Добавить векторный слой…**.

### Шаг 7 — Выберите точки своей территории

Откройте **Вектор → Выборка → Выбрать по расположению…**:

| Поле | Что выбрать |
| --- | --- |
| **Выбрать объекты слоя** | `rural_settlements` |
| **Где объект** | `пересекает` |
| **По отношению к объектам слоя** | `mo` |
| **Изменить текущую выборку** | `создать новую выборку` |

Нажмите **Выполнить**. Выбранные точки подсветятся жёлтым. В таблице атрибутов включите **Показать выделенные объекты** и проверьте, что список не пуст.

<Figure src="images/module1-territory-kit/04-select-location.png"
        alt="Выбор населённых пунктов, пересекающих границу муниципального образования"
        caption="Для учебного набора используйте предикат «пересекает» и слой mo." />

### Шаг 8 — Сохраните выбранные точки

Правой кнопкой по `rural_settlements` → **Экспорт → Сохранить объекты как…**:

- **Формат** — `GeoPackage`;
- **Имя файла** — тот же `output\Фамилия_МО.gpkg`;
- **Имя слоя** — `settlements`;
- **СК** — `EPSG:32636`;
- отметьте **Сохранить только выделенные объекты**;
- оставьте **Добавить сохранённый слой на карту**.

При вопросе о существующем файле выберите **Добавить новый слой**, не перезапись. Выключите исходный `rural_settlements`.

<Figure src="images/module1-territory-kit/05-export-selected.png"
        alt="Экспорт выделенных населённых пунктов в слой settlements"
        caption="Обязательно отметьте «Сохранить только выделенные объекты»." />

<Troubleshoot>

**Ничего не выбралось.** Проверьте: сравниваем `rural_settlements` с `mo`, предикат — `пересекает`.

**В `settlements` попала вся область.** Повторите экспорт с галочкой **Сохранить только выделенные объекты**.

**QGIS предлагает перезаписать файл.** Выберите **Добавить новый слой**, иначе потеряется `mo`.

</Troubleshoot>

### Шаг 9 — Оформите и сохраните карту

1. Для `mo`: **Стиль** → **Нет заливки**, яркая обводка `0,8` мм.
2. Включите подпись по полю `name_short` с белым буфером `1` мм.
3. Для `settlements` выберите заметный цвет. Подписи всех точек не нужны.
4. Поставьте `settlements` выше `mo` и приблизьтесь к территории.
5. **Проект → Импорт/Экспорт → Экспортировать карту в изображение…** → `output\Фамилия_МО.png`.

<Checkpoint title="перед сдачей">

- На карте видны граница с подписью и населённые пункты
- Точки относятся к вашему МО
- Файл называется `Фамилия_МО.png`

## Что мы повторили

- Фильтр оставляет нужную территорию без изменения исходных данных.
- Выбор по расположению находит объекты по предикату `пересекает`.
- При экспорте выборки нужна галочка **Сохранить только выделенные объекты**.
