# gis-lessons

Учебные материалы по дистанционному зондированию и QGIS.
Статический сайт на [Astro](https://astro.build) + Tailwind CSS, публикуется на GitHub Pages.

## Команды

| Команда           | Действие                                    |
| :---------------- | :------------------------------------------ |
| `npm install`     | Установить зависимости                       |
| `npm run dev`     | Дев-сервер на `localhost:4321`               |
| `npm run build`   | Собрать сайт в `./dist/`                     |
| `npm run preview` | Посмотреть собранный сайт локально           |

## Как добавить урок

1. Создайте `src/content/lessons/<имя-урока>.mdx`.
2. Заполните frontmatter (схема — в `src/content.config.ts`):

```yaml
---
title: "Название урока"
description: "Короткое описание для карточки на главной."
duration: "~1.5 часа"
tools: ["QGIS"]
difficulty: "новичок"          # новичок | средний | продвинутый
topics: ["ДЗЗ", "растровый анализ"]   # темы для фильтра на главной
order: 3                        # порядок в списке уроков
cover: "images/<урок>/превью.png"
---
```

3. Картинки кладите в `public/images/<имя-урока>/`.

Поля `lang` и `translationOf` нужны только переводам — см. «Перевод урока
на другой язык» ниже.

### Компоненты в MDX (доступны без импорта)

`<Callout type="info|tip|warning|attention" title="...">`, `<Figure>`, `<Formula>`,
`<VideoEmbed>` — см. `src/components/`.

Четыре блока для занятий, которые студенты проходят самостоятельно:

```mdx
{/* Контрольная точка в конце части: студент сверяется сам, а не поднимает руку.
    Пункты списка получают галочки. Рамка со всех сторон — блок видно
    при пролистывании, в отличие от Callout. */}
<Checkpoint title="конец части 1">
- В правом нижнем углу написано `EPSG:32636`
- Проект сохранён как `Фамилия.qgz`
</Checkpoint>

{/* Файл-спасатель: готовый файл на состояние «после этого шага».
    Отставший догоняет группу, а не выпадает из занятия. */}
<Rescue href="https://disk.yandex.ru/d/..." step="после части 2" label="Скачать проект">
Внутри — проект с подложкой. Откройте и продолжайте с части 3.
</Rescue>

{/* Типовые ошибки шага. Свёрнут по умолчанию — не мешает тем, у кого вышло. */}
<Troubleshoot title="Если не получилось">
**Пункта «Веб» нет в меню.** Модуль не установился…
</Troubleshoot>

{/* Критерий сдачи в конце урока: без него присылают скриншот вместо проекта. */}
<Submit deadline="до конца занятия" where="LMS, задание «Занятие 1»">
**Что прислать:** `Фамилия.qgz` и `Фамилия_screen.png`
</Submit>
```

### Перевод урока на другой язык

Язык выбирается **не у всего сайта, а у отдельного урока**: у большинства
уроков переключателя нет, он появляется только там, где перевод реально есть.

Чтобы перевести урок:

1. Создайте рядом файл `<имя-урока>.<код языка>.mdx` — например
   `qgis-first-project.fr.mdx`.
2. Во frontmatter перевода добавьте два поля:

```yaml
lang: "fr"                        # код языка
translationOf: "qgis-first-project"   # id основного урока (имя его файла)
```

3. Переведите текст. `difficulty` и `topics` оставьте **как в оригинале**:
   это ключи (фильтры на главной, перевод подписи), а не видимый текст.
   `title`, `description`, `duration`, `qgis` — переводятся.

Что произойдёт дальше само:

| | |
| :-- | :-- |
| Адрес перевода | `/lessons/qgis-first-project/fr/` (у оригинала адрес не меняется) |
| Переключатель `RU · FR` | появится в шапке урока — на обеих страницах |
| Карточка на главной | останется одна, с плашкой доступных языков |
| Подписи интерфейса | «Сверьтесь», «Что сдать», «Содержание», кнопки шагов и т.д. — переводятся сами |
| `<html lang>` | проставится по языку страницы |

Языки и все подписи интерфейса — в `src/i18n/ui.ts`. Чтобы добавить язык,
допишите его код в `LANGS`, название в `LANG_NAMES`, словарь рядом с `fr`
и код языка в `lang:` в `src/content.config.ts`.

Компоненты узнают язык из адреса страницы (`getLangFromUrl(Astro.url)`),
а не через пропсы: содержимое урока приходит в `<slot>`, до него пропсы
не доходят.

**Прогресс по шагам считается отдельно для каждого языка** — отметки
хранятся по адресу страницы, а якоря шагов в переводе другие. На карточке
главной показывается тот язык, где пройдено больше.

### Версия QGIS

Поле `qgis` во frontmatter (`qgis: "3.40 LTR"`) выводится отдельной плашкой
в шапке урока и на карточке на главной. В разных версиях QGIS пункты меню
называются по-разному, поэтому версия должна быть видна сразу, а не в тексте.

### Короткие названия для оглавления

Длинный заголовок шага можно сократить для сайдбара маркером `||`:

```md
### Шаг 2 — Добавьте подложку Yandex через QuickMapServices || Шаг 2. Подложка Yandex
```

На странице останется полный текст (до `||`), в оглавлении — короткий.
Якорь (`#id`) строится по полному тексту, поэтому добавление короткого имени
не ломает существующие ссылки. Реализация: `src/plugins/remark-toc-labels.mjs`.

### Прогресс читателя

У каждого шага (заголовок `h3`) появляется кружок-чекбокс. Отметки хранятся
в localStorage браузера читателя; прогресс виден в сайдбаре урока и на
карточках главной страницы. Серверного хранения нет.
